БЫСТРЫЙ СТАРТ
==================================

1. Установка:
   sudo ./install.sh

2. Настройка:
   nano ~/.vpn_proxy

   Один из четырёх форматов:
     https://example.com/sub/vless/UUID   - подписка (выбор страны)
     incy://crypt1/PAYLOAD                - подписка INCY (через официальный клиент)
     vless://UUID@HOST:PORT?params#name   - одиночный VLESS
     ss://BASE64@HOST:PORT?params#name    - Outline / Shadowsocks
     IP:PORT:USER:PASS                    - HTTP-прокси

3. Использование:
   vpn curl ifconfig.me
   vpn wget https://example.com
   vpn apt update

4. Если подписка - выбор страны:
   vpn list                     - список стран
   vpn use de                   - страна по умолчанию
   vpn -c jp curl ifconfig.me   - разово через Японию

ОПИСАНИЕ ФАЙЛОВ
==================================

vpn
---
Bash-скрипт который:
- Читает конфигурацию из ~/.vpn_proxy
- Определяет режим: подписка, VLESS, Outline/ss:// или HTTP-прокси
- Поднимает xray под нужную страну (для VLESS и подписки)
- Поднимает outline-proxy (для ss://)
- Поднимает коробку с клиентом INCY (для incy://)
- Устанавливает переменные HTTP_PROXY и HTTPS_PROXY
- Запускает переданную команду
Подкоманды: list, use, status, stop, update, incy

vless_parser.sh
---------------
Разбирает vless:// URL на составляющие (UUID, хост, порт,
транспорт, параметры reality/tls, имя сервера).

vless_to_xray.sh
----------------
Генерирует конфиг xray из разобранного VLESS URL и управляет
процессом xray (start/stop/restart/status).
Транспорты: tcp, ws, xhttp, httpupgrade, grpc.

subscription.sh
---------------
Скачивает подписку, декодирует тело (v2ray-JSON, base64 или
plain text), вытаскивает список серверов со слагами стран,
кэширует его и ищет по нему.

v2ray_json.py
-------------
Превращает подписку в формате v2ray-JSON (массив целых
Xray-конфигов, как у Remnawave) в список vless:// ссылок.
Берёт только proxy-outbound; протоколы, которые vpn не тянет
(hysteria, trojan), отбрасывает. Нужен python3, только stdlib.

incy_box.sh
-----------
Ставит официальный клиент INCY (portable zip / dmg, sha256
проверяется) в ~/.local/share/vpn/incy и держит его в фоне в
режиме PROXY_ONLY. Изоляция: свой домашний каталог INCY,
заглушки вместо networksetup/gsettings/xdg-mime, на Linux —
Xvfb и bubblewrap. Импортирует incy:// ссылку, выбирает сервер,
отдаёт vpn адрес локального mixed-порта с паролем.

incy_state.py
-------------
Читает preferences.json, incy.db и xray_config.json клиента
INCY: список серверов, выбор сервера, адрес порта, фиксация
HWID (vpn incy hwid). Только stdlib; параметры через
переменные окружения.

ss_parser.sh
------------
Разбирает и чистит ss:// URL (SIP002 / Outline): отрезает имя,
убирает outline=1, сохраняет prefix.

ss_to_outline.sh
----------------
Управляет локальным хелпером outline-proxy: запуск, остановка,
статус. Слушает HTTP на 127.0.0.1:18082.

test_vless.sh
-------------
Тесты: разбор URL, генерация конфигов (включая проверку через
xray -test), декодирование подписки и поиск страны.

vpn_proxy.example
-----------------
Пример файла конфигурации с данными прокси.
Копируется в ~/.vpn_proxy при установке.

install.sh
----------
Автоматическая установка:
- Копирует vpn и вспомогательные скрипты в /usr/local/bin/
- Создает ~/.vpn_proxy из примера
- Устанавливает права доступа

uninstall.sh
------------
Удаление:
- Останавливает запущенные процессы xray
- Удаляет скрипты из /usr/local/bin
- Опционально удаляет ~/.vpn_proxy, конфиг xray и кэш подписки

РАЗВЕРТЫВАНИЕ НА НОВОЙ СИСТЕМЕ
==================================

Шаг 1: Скопировать папку proxied_bash на целевую систему:

   scp -r proxied_bash user@host:~/
   
   или
   
   rsync -avz proxied_bash/ user@host:~/proxied_bash/

Шаг 2: Подключиться к системе:

   ssh user@host

Шаг 3: Перейти в папку и установить:

   cd ~/proxied_bash
   sudo ./install.sh

Шаг 4: Настроить прокси:

   nano ~/.vpn_proxy

Шаг 5: Проверить работу:

   vpn curl ifconfig.me

ГОТОВО!

ТРЕБОВАНИЯ
==================================

- Linux/Unix система
- bash
- python3 (только для v2ray-JSON подписок и incy:// ссылок; stdlib, без pip)
- для incy:// на Linux: xvfb, x11-xserver-utils (xrandr), bubblewrap, unzip (x11vnc — для `vpn incy ui`)
- sudo доступ для установки
- Программы должны поддерживать HTTP_PROXY переменные окружения
